# DP_WeatherConstructor — движковые песчаные бури и вьюги на любой карте (DayZ 1.30+)

Переносит на любую карту две движковые погодные системы (клиентам ничего не нужно,
мод подключается только на сервере как `-servermod`):

- **Песчаная буря** — `SandstormController`, механика Badlands/Nasdara: движущийся
  пространственный фронт с частицами, урон здоровью/шоку с ванильными укрытиями
  (крыша/машина/подземка) и защитой лица (очки/маска), ванильные силикоз/кашель.
- **Вьюга** — механика Сахала (thundersnow): снегопад + ветер + мгла метели,
  случайный старт при пасмурной погоде, холод вычетом из температуры мира,
  после метели — «замело» (лёгкий снег и приземная дымка) и таяние. Скриптовый
  замок снега у Черноруси снимается на время вьюги автоматически.

Проверено живым сервером и ванильным клиентом: DayZ 1.30, Чернорусь.

## Настройка

`DarkProjectConfig/WeatherConstructor/config.json` в профиле сервера (паттерн
DP_AdminMenu): создаётся с дефолтами при первом старте. Пример —
[example/config.json](example/config.json).

| Секция | Что |
|---|---|
| `Enabled` | **главный выключатель всей механики** (первая настройка) |
| `AutoStart` / `RandomStart` / `Damage` | песчаная буря: цикл / случайный старт (шанс при пасмурно, как на Nasdara) / урон |
| `Blizzard` | вьюга: `RandomStart` (те же ключи), `GatherMinutes`/`DurationMinutes`/`MeltMinutes`, `SnowfallIntensity`, `SnowfallThreshold`, `WindMaximum`, `VolFogStormDensity` (мгла), `VolFogMeltDensity`/`MeltHeightDensity` («замело»), `TemperatureDelta` (холод), `Thundersnow` |
| `Logging` | строки урона и статус в script-лог |

Маршрут песчаной бури (`startPosition`/`endPosition`, частицы) — в `config.cpp`
аддона (CfgWorlds >> Weather >> Sandstorm): его читает сам движок, скриптового
сеттера нет. При необходимости позиции выносятся в JSON graft-плагином —
сознательно не реализовано.

Снег на земле не лежит и не накапливается — такой системы в DayZ нет вовсе
(у Сахала земля — зимние текстуры мира). Вьюга даёт снег в воздухе, мглу,
холод и промокание; «зимняя земля» — отдельная тема террейн-мода.

## Сборка и установка

```powershell
.uild.ps1     # -> @DP_WeatherConstructorddons\DP_WeatherConstructor.pbo
```

Только сервер: `-servermod=@DP_WeatherConstructor`. **Не** подключать мод на
клиенте (`-mod`) — секция Sandstorm в CfgWorlds роняет клиент в интро-сцене.

## Важно (проверено живыми прогонами)

- `particlePath` в секции Sandstorm обязателен: дефолтный путь — файл DLC
  Badlands, без замены ванильный клиент падает при входе в стену (0x400F0).
- Звуковые наборы песчаной бури (`SandStorm_*_SoundSet`) в базовой установке
  отсутствуют — буря беззвучна (warning, не фатально).
- На серверах с тяжёлым модсетом мерж секции может валить сервер на парсинге
  конфигов — при падении бисектить модсет (на сборке @CF+@test+@server
  воспроизводилось, на живом @server — работало).
